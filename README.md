# 🎨 Pix Art

**Pix Art** هو مشروع تطبيق رسم وتلوين تفاعلي مبني بـ **HTML** و**CSS** و**JavaScript**، يضم واجهة داكنة مزودة بمساطر وأشرطة تحكم جانبية للسمك والشفافية وشريط حالة سفلي[cite: 1, 2, 3].

## ملفات المشروع
- `index.html`: هيكل الواجهة وشريط الأدوات ولوحة الألوان ومنطقة العمل[cite: 2, 3, 6, 7].
- `style.css`: تنسيق التصميم الداكن، المساطر، أشرطة السحب، وشريط الحالة[cite: 2, 3, 6, 7].
- `app.js`: منطق الرسم، الأدوات، التراجع، الشبكة، وحفظ اللوحة[cite: 2, 3, 6, 7].
- `main.js`: إعداد نافذة تطبيق سطح المكتب باستخدام Electron وأيقونة التطبيق[cite: 2, 3, 6, 7].
- `logo.ico`: أيقونة المشروع[cite: 2, 3, 6, 7].
